# Find-a-photo-of-your-child

Поиск фотографий с лицом ребёнка
Этот скрипт помогает автоматически находить фотографии с определённым лицом (например, ребёнка) среди большого количества снимков с праздников, утренников и прочих мероприятий. Он решает проблему ручной сортировки и позволяет сохранить только нужные изображения в отдельную папку.

🔍 Что делает скрипт
Ищет все фотографии с лицами в указанных папках (--mode all);

Или находит только те лица, которые совпадают с эталонными фотографиями из папки REFERENCE_DIR (--mode reference);

Поддерживает многопоточную обработку для ускорения;

Работает с .jpg, .jpeg, .png, .heic, .webp;

Сохраняет копии найденных файлов в DESTINATION_DIR;

Формирует текстовый отчёт по итогам работы.

🧠 Как это работает
Используется библиотека InsightFace для распознавания и сравнения лиц;

В режиме reference код извлекает embedding-лица из эталонных изображений и сравнивает его с embedding'ами найденных лиц на всех фото;

В режиме all используется обычный детектор лиц из OpenCV (YuNet);

Картинки предварительно уменьшаются для ускорения обработки (максимальный размер — 1200px по длинной стороне).

🗂 Структура папок
📥 SEARCH_PATHS: где искать фотографии (указывается список путей);

🧒 REFERENCE_DIR: папка с эталонными изображениями нужного лица;

📤 DESTINATION_DIR: куда копируются подходящие изображения.

🚀 Как использовать
Установи зависимости:

bash
pip install insightface onnxruntime opencv-python-headless pillow tqdm
Запусти скрипт:

Чтобы найти все фотографии с лицами:

bash
python Findchild.py --mode all
Чтобы найти только фото с конкретным лицом:

bash
python Findchild.py --mode reference
⚠️ Режим reference работает только при установленной библиотеке insightface и наличии эталонных изображений в папке REFERENCE_DIR.

📊 Вывод
В конце выполнения ты получишь:

Общую статистику: сколько файлов найдено, сколько лиц обнаружено, сколько файлов скопировано;

Подробный лог и файл face_detection_report.txt в целевой папке с результатами.


💡 Замечания
Не проверено на Windows;

Не проверено на "чистой" системе — возможно, потребуется установка дополнительных системных библиотек;

HEIC и WEBP читаются через PIL.

🧒 Зачем это нужно
У меня накопились сотни фотографий с детских утренников, где мой ребёнок в толпе других детей. Я устал вручную просматривать все снимки. Этот скрипт за пару минут нашёл и скопировал только те фото, где есть мой сын. Экономия времени — колоссальная.
