## 🎯 Проект: Find Child Photos (GUI-версия)

### Суть
Кроссплатформенное десктоп-приложение (Windows + macOS), которое повторяет функционал скрипта `Findchild.py` в удобном графическом интерфейсе.

### Два режима работы
| Режим | Описание |
|-------|----------|
| **All faces** | Найти все фотографии, где есть хотя бы одно лицо |
| **Reference person** | Найти фотографии конкретного человека по эталонному фото |

### Ключевые требования
- ✅ Кроссплатформенность: Windows 10/11 + macOS 10.15+
- ✅ GUI: PySide6 (Qt 6)
- ✅ Многопоточность: обработка фото не блокирует интерфейс
- ✅ Прогресс-бар в реальном времени
- ✅ Поддержка форматов: JPG, JPEG, PNG, HEIC, WEBP
- ✅ Отчёт в текстовом файле
- ✅ Копирование найденных фото в отдельную папку
- ✅ Инсталляторы: `.exe` (Windows) + `.app`/`.dmg` (macOS без подписи)

## 🧵 Многопоточность

### Правило: GUI никогда не должен зависать
- Вся тяжёлая работа (сканирование, детекция, распознавание) — в `QThread`
- Прогресс передаётся через сигналы: `worker.progress_updated.connect(progress_bar.setValue)`
- Отмена операции: флаг `worker.should_stop`, проверяется в цикле

### Структура Worker
```python
class PhotoWorker(QThread):
    progress_updated = Signal(int, str)  # процент, сообщение
    photo_found = Signal(str)            # путь к найденному фото
    finished = Signal(dict)              # результаты
    
    def run(self):
        # 1. Сканирование папок
        # 2. Детекция лиц
        # 3. Распознавание (если режим reference)
        # 4. Копирование результатов
```

## 📊 Функционал (из исходного скрипта)

### Режим 1: All faces
1. Пользователь выбирает папку с фото
2. Приложение сканирует все файлы (JPG, PNG, HEIC, WEBP)
3. Для каждого фото: детекция лиц через YuNet
4. Если лицо найдено → фото копируется в `output/found/`
5. В конце: текстовый отчёт `report.txt`

### Режим 2: Reference person
1. Пользователь выбирает папку с фото
2. Пользователь выбирает эталонное фото (reference.jpg)
3. Приложение:
   - Извлекает embedding из эталона (InsightFace)
   - Для каждого фото: детекция лиц → embeddings → сравнение
   - Если косинусное расстояние < порога → фото копируется
4. В конце: текстовый отчёт

### Настройки (диалог)
- Количество потоков (по умолчанию: 6)
- Порог сходства для режима reference (по умолчанию: 0.4)
- Папка для результатов (по умолчанию: `./output/found/`)
